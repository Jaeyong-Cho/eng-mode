# Actions

An action describes **what to do**. It should be concrete enough to perform, review, or verify.

## Template

```markdown
# <Action title>

- **ID**: `<filename-without-extension>`
- **When**: The signal or situation that calls for this action.
- **Steps**:
  1. A concrete step.
  2. Another concrete step.
- **Done when**: Observable completion criteria.

```

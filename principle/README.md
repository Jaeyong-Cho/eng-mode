# Principles

A principle describes **how to think** about a situation. It should guide trade-offs without prescribing one exact implementation.

## Template

```markdown
# <Principle title>

- **ID**: `<filename-without-extension>`
- **Rule**: State the guidance in one sentence.
- **Why**: Explain the reasoning and trade-off.

## Applies to

- [<situation>](../situation/<situation>.md)

## Actions

- [<action>](../action/<action>.md)
```
